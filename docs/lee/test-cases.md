# GatePass VR 기능 테스트 항목과 결과 (업무 [23]·[24], 작성 이씨)

- 대상: `Assets/_GatePassVR/Scenes/Airport_Lee.unity` (feature/lee-full-flow)
- 방법 표기: **Sim** = Unity Editor Play + XR Device Simulator. 컨트롤러 방향·위치는 시뮬레이터 상태값을 코드로 바꿔 조준했다.
  Ray 판정·Hold·Grab 연결·물리는 실제 XRI와 프로젝트 컴포넌트가 처리했다. 잡기는 `XRInteractionManager.SelectEnter`로 했다
  (손잡이 버튼 입력 대신). **Quest** = 실기기.
- 결과: ✅ 통과, ⚠️ 통과했지만 주의, ❌ 실패, ⬜ 아직 안 함

## 3. 발견한 문제와 처리 ([26])

| # | 문제 | 원인 | 처리 |
|---|---|---|---|
| B1 | 체크인에서 건넨 여권이 고정되어 S4·S8에서 못 씀 | 돌려주는 자리 없음 | ReturnPoint + S2-1b |
| B2 | Reset하면 여권이 출발 지점으로 감 | 처음 위치로만 복구 | Step 진입·이동 완료 위치로 복구 |
| B3 | 스캔 뒤 여권을 두고 가면 S8-1에서 막힘 | 챙기라는 안내 없음 | S4-3 |
| B4 | 가방을 먼저 놓으면 S3-2에서 막힘 | 앞 Step 중 성공 신호 무시 | StepSuccessRelay 따라잡기 |
| B5 | 돌려준 여권이 멀리 날아감 | XRI가 놓은 뒤 던지기 속도를 다음 Late 단계에 넣는데, 김씨 코드가 물건을 비활성화해 반환할 때 적용됨. 이동 직후라 속도가 매우 큼 | 건넬 때·Reset 때 그 한 프레임만 던지기 끔 |
| B6 | 원거리로 잡은 여권이 몸 앞 1.2m에 떠서, 이동 직후 체크인 칸에 저절로 들어감 | Far Attach = Far | 공항 물건 6개 Far Attach Near |
| B7 | 보안검색에서 양손을 비우려 내려놓은 서류를 두고 가면 탑승구에서 막힘 | 물건이 따라오지 않음 | CarryAlong(이동할 때 4m 넘게 떨어진 여권·탑승권을 발옆으로) |

## 4. 아직 확인 못 한 것
- Quest 실기기 전체(5단계). 실제 손잡이 버튼·B/Y 버튼, 한글, 프레임.
- 효과음·음성 크기와 겹침(이씨 청취).
- 탑승구 정면 "탑승하기" 표지판이 실수로 눌리는지(시뮬레이터 기본 방향에서 저절로 눌렸음).
- 머리에 붙은 안내판이 표지판과 겹쳐 읽기 어려운 장면(체크인에서 캡처로 확인, 김씨 UI 영역).
